# DevOps: The Final Deployment 🎬

Original 25-minute Hinglish 3D-style workplace comedy for YouTube.

**Status:** Preproduction. **Budget cap:** AED 1,000. **Aspect:** 16:9. **Target:** 1920x1080, 24 fps.

## Start here
1. Read `docs/production-plan.md`, `docs/screenplay.md`, and `characters/character-bible.md`.
2. Generate consistent character reference images before any video.
3. Produce a 60–90 second pilot and validate voice, continuity, and cost.
4. Generate approved clips; keep original video/audio in external storage, not Git.
5. Use `scripts/validate_project.py` and `scripts/make_shotlist.py`.
6. Use FFmpeg only after the audio animatic and footage are approved.

## Layout
- `docs/`: story, production, budget, publishing
- `characters/`: character and voice bible
- `prompts/`: image/video/voice prompt templates
- `scenes/scene-XX/`: per-scene production briefs
- `scripts/`: validation, shot list, optional video assembly
- `audio/`, `video/`, `subtitles/`: placeholders; large assets excluded from Git
