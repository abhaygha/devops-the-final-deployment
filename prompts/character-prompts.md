# Character reference prompts

Create and approve the characters before producing scene animation. Generate each character separately; do not put the four characters in one image. Keep the same visual style, proportions, and lighting for all four.

## Generation workflow

1. Generate one clean, full-body three-quarter reference for Mr. Deadline using the prompt below.
2. Review and approve his face, silhouette, costume, and colors. Save that image as his master reference.
3. Use the approved master as an image reference to make a front, side, and back turnaround, followed by a separate expression sheet.
4. Repeat for Captain Jira, Baba Kubernetes, and Chintu YAML. Reuse the same style description and image-generation settings where available.
5. Keep the approved master images outside Git if they are large. Use the same character reference images for every scene and video prompt.

If the image tool struggles to make a readable turnaround or expression sheet, generate each view or expression as a separate image using the approved master as its reference.

## Shared visual style

Original stylized 3D animated workplace comedy, appealing rounded proportions, expressive readable face, polished feature-animation lighting, soft global illumination, clean neutral light-gray studio background, full body visible, centered single character, consistent anatomy and costume, high-quality character design, no props unless specified, no text, no labels, no watermark, no logos.
